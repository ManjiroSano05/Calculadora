# Calculadora de Matrizes em C

Programa desenvolvido em linguagem C para realizar operações entre matrizes.

## Funcionalidades

- Escolher a quantidade de matrizes (de 2 a 10).
- Informar as dimensões e os valores de cada matriz.
- Realizar soma, subtração e multiplicação.
- Mostrar a matriz resultante.

## Como executar

Compile o arquivo `main.c` com um compilador C, como o GCC:

```bash
gcc main.c -o calculadora
./calculadora
```
